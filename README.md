# Book Finder

Book Finder is a React app for discovering free ebooks. After signing in with Google, you can search for a book and browse freely available books from the Google Books API, sorted newest first, with pagination. Selecting a book opens a page with its details, an embedded reader preview, and PDF/EPUB download links when available. It's built with React, Vite, Material UI and React Router, and is deployed to GitHub Pages.

**Live page:** https://ashmaitelly.github.io/book_search/
